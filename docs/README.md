# docs/

Документы в этом каталоге хранятся **зашифрованными**: файлы `*.md.sops`.
Открытых `.md` в git нет — они в `.gitignore`.

Причина: репозиторий публичный. Секретов (ключей, паролей) в документах нет,
но есть подробная карта инфраструктуры — какой хост что держит, как устроены
механизмы секретов, куда ведут аварийные пути. Код читать полезно всем,
карту — не всем.

Прочитать:

    export SOPS_AGE_KEY_FILE="$PWD/.age/age.key"
    sops -d --input-type json --output-type binary docs/<имя>.md.sops > docs/<имя>.md

Записать изменения обратно:

    sops -e --input-type binary --output-type json docs/<имя>.md > docs/<имя>.md.sops

Правила — в `.sops.yaml`, получатель age тот же, что у остальных секретов
репозитория.
